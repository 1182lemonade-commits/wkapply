WK Admin

WK 관리
서버를 선택하면 해당 서버의 관리 데이터가 표시됩니다.

새 서버 추가

서버 생성 후 해당 서버가 자동으로 선택됩니다. 최초 상태는 Force Closed입니다.

신청 변경사항

선택한 서버의 신청 수정 이력입니다. 최신 변경부터 표시하며, 한 번에 여러 항목이 바뀌면 항목별로 표시합니다.

접수 방식

신청서 개폐 방식을 설정합니다.

Excel 이메일 발송

이 서버의 WK 신청 결과를 받을 이메일을 최대 3개까지 관리합니다. Auto 마감 후 10분 자동 발송과 수동 즉시 발송에 사용됩니다.

현재 결과 즉시 전송

현재 저장된 이 서버의 응답만 Excel로 만들어 활성 수신 이메일에 즉시 전송합니다.

최근 발송 기록

마지막 동의 체크박스

활성화 항목은 최대 3개입니다. 각 언어 문구를 모두 입력해야 저장됩니다.

새 동의 항목

WK 응답

공동구매 관리

선택한 서버의 공동구매 일정, 제목, 상품과 신청 내역을 관리합니다. 영어 제목은 필수이며 다른 언어 제목이 비어 있으면 공개 화면에서 영어 제목을 사용합니다.

공동구매 목록

마감된 공동구매도 자동 삭제 전까지 표시됩니다.

티어 관리

기존 신청서의 기록 보존을 위해 사용하지 않는 티어는 삭제보다 비활성화를 권장합니다.

연맹 관리

기존 신청서의 기록 보존을 위해 사용하지 않는 연맹은 삭제보다 비활성화를 권장합니다.

서버 관리

영구 삭제는 비활성화된 서버에서만 가능합니다. 삭제하면 해당 서버의 설정, 티어, 연맹, 동의항목, 신청 결과가 함께 삭제되며 복구할 수 없습니다.
